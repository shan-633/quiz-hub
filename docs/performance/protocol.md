# 进度方案 A/B 压测协议

本次为隔离性能实验，不改变3001服务、产品路由或真实作答。A为当前代码的完整记录扫描和3秒轮询；B为实验用独立SQLite进度摘要及SSE推送。双方学生保存仍调用当前registerAttempts，保留整份作答JSON写入、答案校验、资产校验、身份/CSRF和revision检查；不混入逐题存储的收益。

使用真实2022北京卷26题快照，合成学生答案和手写笔迹。分别建立100活跃/900历史及300活跃/2700历史两份数据集。同一数据集复制给A/B，每轮独立子进程、独立数据库、WAL、真实本机HTTP和连接复用，压测发生器与服务端分进程。启动、摘要回填、预热不纳入稳态耗时，另报回填时间。关闭双方压测服务的IP限流与日志以测业务处理上限，线上配置保持不变。

测试前验证A/B初始摘要完全相同；B更新、清空和交卷同步、事务回滚、SSE元数据及权限需通过正确性测试。查询压力和学生写入压力采用固定并发闭环负载；教学混合负载计划每学生2秒保存一次，每个学生最多一个在途请求，慢时延期补发并记录实际完成时间、调度迟延。同时A教师3秒轮询、B教师保持SSE连接，测实际发起保存至教师客户端首次收到本次或更新版本的耗时；不把闭环负载解释为稳定固定到达率。标识取同一次提交的attempt.updatedAt，双方实验响应头返回它，避免与answer.updatedAt的毫秒差；跨浏览器渲染不在测量范围。

正式运行每种模式重复3轮、交替先后顺序，保留原始逐轮结果并报告中位数。记录成功/错误数、吞吐量、延迟P50/P95/P99、服务进程CPU、RSS、事件循环延迟、响应/事件体字节数。延迟倍数= A耗时/B耗时，吞吐倍数=B吞吐/A吞吐；分开报告查询、保存和通知，不能合成整站倍数。B摘要/SSE会增加写时维护和连接成本，可能使纯保存变慢，照实报告。

本机回环、合成数据、短时单实例实验不能等同公网、真机、图片解码或多节点容量；不预设某个提升倍数。完整重现命令及测试参数写入最终报告。
