# 题库文件导入实施计划

**Goal:** 提供可移植题库协议、介绍文档和管理员校验预览/原子导入流程。

**Architecture:** 严格共享协议 Schema 与领域验证；服务器解码验证图片、构造预览与事务入库；独立前端弹窗接入现有 AdminPage。保持当前服务、SQLite 和版本数据。

**Tech Stack:** 现有 React、Zod、Fastify multipart、Sharp、node:sqlite；无需新增依赖。

- [x] 测试先行：协议解析、语义及限制用例失败；实现 shared/bankImport.ts。
- [x] 测试先行：真实 API 校验无写入、权限、提交、重复、原图、草稿及发布、回滚；实现 server/import 与 routes/bankImport.ts、增加导入记录集合。
- [x] 增加六题型可运行示例、北京原图真题包、机器 Schema 和中文协议介绍文档；生成并验证静态下载文件。
- [x] 测试先行：导入 UI 的校验错误阻断、文件切换、成功及提交失败；实现 BankImportDialog、图像预览映射、管理员入口与响应式样式。
- [x] 全套测试/构建/自审，通过后重启本地服务；浏览器检查非法及合法文件、发布选项和预览布局；保留本地入口并交付文档与源码。

Review Focus：深层输入在递归 Schema 前拒绝；真实 MIME 和解码不是只查扩展名；未定义答案/图片引用不能静默忽略；数据库/文件同步失败清理；相同文件并发提交仅一次。测试覆盖每项。

当前用户已授权设计并实施，使用本会话原生执行，不要求额外审批。

Ruling: 示例下载从public改为content-assets并经管理员API返回，示例包含真实标准答案，不应匿名公开。结构限制同时保证导入题目能保存回现有编辑器。
