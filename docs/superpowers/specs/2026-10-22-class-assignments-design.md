# 班级组、推送任务及限时作答

教师管理自己已关联的学生，可建立多个班级组，同一学生可加入多个组。管理员仍负责账号与师生归属，教师不能借分组关联其他学生。组内成员变更不修改已推送任务的收件名单。

推荐独立任务层：题库/试卷是教学素材，推送任务保存题目与计时规则快照、目标班级组和去重后的学生名单。相比直接在题库挂班级，它支持同一套内容面向不同班级设置不同截止时间；相比复制题库则避免重复维护。原有公开给关联学生的目录保留，定向任务仅在收件学生的“班级任务”中出现。

教师可在导入完成后或已有题库卡片中选择“推送班级”。任务可选绝对截止时间、答题分钟数、是否强制到时交卷。题库和试卷也可设置默认答题分钟数及强制规则，推送时可覆盖；原有minutes继续是建议用时，不自动成为强制时限。

第一次打开任务创建唯一答卷并确定开始时间；重复打开和刷新返回同一答卷，不可用fresh重做绕过。一份任务包含多个组时同一学生只收到一份。计时结束时间为绝对截止和首次开始加时长中的较早值。未开启强制时只提示超时并记录迟交，仍可完成。开启强制时，截止后未开始的任务显示已截止；进行中的答卷由服务端自动提交已同步内容，进入原有教师批改流程。未同步或截止后上传的内容不能补入。

自动交卷由独立截止索引和单进程定时器处理，启动时补处理到期记录；作答、上传与读取入口再次核验，避免后台/关页/断网绕过。客户端以服务器时钟校准倒计时，每秒更新，到时锁定编辑、通知并返回任务/历史状态入口；网络失败时保持锁定并重试，不假装已交卷。普通非强制练习不受影响。

服务端新模块负责班级/任务；计时模块负责快照、到期判定和提交，与聊天分离。保留已有教师批改、进度SSE及权限函数。学生任务有未开始、进行中、待批改、已批改、已截止状态；教师任务可查看人数和各学生状态/逾期情况。

验证重点：非关联学生和跨教师分组/推送拒绝、重叠组去重、不可绕过任务计时、软超时可提交、硬超时拒绝改写/上传、无人在线自动交卷、重启补交、正确答案隐藏、旧题库和答卷无计时迁移。桌面/平板/手机检查并备份后部署现有局域网服务。
