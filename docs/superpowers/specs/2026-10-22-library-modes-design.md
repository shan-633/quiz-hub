# 展示练习与分配任务

题库/试卷增加deliveryMode：showcase展示练习、assigned分配任务。缺少该字段的既有内容按assigned处理，不重写旧文档。新建和导入默认assigned。教师可在编辑及列表分区切换。展示练习发布/开始要求标准答案完整；草稿阶段可继续录题。

展示练习发布后，关联学生可见，仍遵守开放时间和计时规则。学生交卷后立即公布题目快照中的答案；仅单选、多选及混合题的选择小问自动评分，其余部分由学生自评。自评复用教师判定/分数/备注表单，答案只读；只能编辑自己的已交展示练习，自动选择分不可覆盖。自评有revision冲突保护，全部完成后确认锁定，明确标为自评成绩。

分配任务仅推送后才对收件学生可见。学生“班级任务”使用推送题目、名单和时间快照；目录接口可返回已推送内容的元信息，界面引导前往班级任务。无assignmentId的开始请求只解析为学生已收到的任务，不允许新建自由作答；fresh不能绕过唯一答卷。学生PDF及题干图片必须来自已开放推送快照，不能读取源库后来增加的未推送题。展示练习不提供推送操作，避免混淆成绩来源。

答卷保存gradingMode快照（self/teacher）。旧答卷无此字段时保持教师流程，不因切换题库类别改变已有成绩、权限或公布时机。展示交卷不进入教师待批改箱，分配任务不开放学生自评。教师原批改仍保持选择初评和最终发布；学生自评不写teacherFeedback。

混合题自评只给非自动部分判分：保留选择小问的自动明细，手动满分=总分减自动部分满分，学生填写分数与自动部分相加。纯选择题只读。自评完成前可调整人工分，完成后锁定；原始答案始终只读，标准答案不能由学生改写。

界面：教师题库列表按两类分区并有类别标记，学生首页展示练习、班级任务显示推送。作答历史增加“待自评”；展示交卷页直接给答案和“开始自评”。共享批改组件处理教师和自评表单，服务端使用不同端点和权限。

验证权限、未推送隐藏、分配快照与素材/PDF隔离、展示交卷答案/仅选择自动、自评分数与混合锁定、冲突/完成/其他学生拒绝、教师任务不能自评、类别切换后旧记录不变。旧教师批改测试使用真实推送fixture补齐前置条件，保留原断言。临时数据库浏览器验收，备份后部署局域网。
