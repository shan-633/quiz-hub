# 题库文件导入设计

用户要求：制定格式化题库文件协议、提供介绍文档，在现有管理员端校验并导入合格题库。沿用现有六类题型、内容块、发布版本和学生作答模型。

采用单文件 UTF-8 JSON，`format=zhixu.question-bank`、`version=1.0`。顶层为 bank、questions、assets；文件内 ID 仅供引用，新库、题目、图片由服务器生成内部 ID。无覆盖/合并已有题目功能，保留历史作答。图片内嵌标准 Base64，允许真实 PNG/JPEG/WebP，保留原字节，不抓取外链，不接受 SVG。可移植题库可由外部程序生成；Excel/Word/PDF 自动识别及 ZIP 是后续能力。

格式严格校验未知字段、必填值、结构深度、ID 唯一性、图片引用、答案、题型约束、分数、表格列数及公式。复用现有领域校验并补充导入语义约束。20 MiB 文件、200 题、100 图、单图 5 MiB、图片不超过 2500 万像素、结构深度24，单题补齐系统字段/图片宽高后最多20000节点。图片需实际解码验证，不能只相信 MIME。错误含 JSON 路径；手工评分提示为非阻断警告。

新增管理员 API：POST /api/admin/bank-import/validate 与 /commit，multipart file。验证不写文件或数据库。返回文件摘要、题型/分数统计、完整预览及图片映射。提交带验证摘要、发布选项，服务端重新验证并比较摘要。文件内容 SHA256 作为重复导入键（忽略 UTF-8 BOM，其他字节变化视为新文件）；同内容重试返回原题库，不改变已导入状态。草稿默认、显式选择发布；草稿也必须满足完整协议与题目规则。

所有图片和题目通过后，图片写入随机生成路径；SQLite 事务写入图片元信息、题库、题目、发布版本及导入记录。失败回滚并清理本次创建的文件。单进程同步提交区避免并发重复插入，旧数据不覆盖。发布后学生 API 仍剥离 solution，未发布题库不公开。

管理页新增导入按钮、文件选择与校验、错误/警告列表、统计、逐题预览、参考答案、草稿/发布选择、导入结果和跳转题目管理。提供协议 Markdown、JSON Schema、六题型示例、可移植2022北京原图真题示例下载。所有下载示例放在非公开content-assets目录，下载经管理员API权限校验，防止标准答案匿名泄漏；示例来源标注，协议示例不混入真实卷。手机/平板/桌面可浏览。

验收覆盖无副作用校验、精确错误、非法图片/引用/答案/未知字段、学生权限、CSRF、失败回滚、重复与并发重试、草稿及发布、原图字节、学生答案保密；浏览器实测错误及成功导入流程。文档、示例、机器 Schema 与运行校验同步。
