# 同一道题的逐栏评卷

教师批改页和学生自评页按题目快照识别多个空格、小问。在同一道题内，每一空、每一小问都有独立评分栏目；表格空格按题干出现顺序排列，填空小问的总分不会再重复计分。

## 评价与切题

每个栏目必须明确选择正确、错误或部分正确。正确为该栏满分，错误为0分，部分正确须大于0且小于该栏满分；零分栏目也要明确判定，不能选部分正确。正确答案和评语可选，教师可分别填写，自评只填写备注。

有任何人工栏目未评或分数无效，不能保存本题，也不能通过上一题、下一题或答题卡切换到其他题；界面提示遗漏位置。所有栏有效后，先“保存本题批改/自评”，或点击“保存并下一题”一次完成保存与切换。自动初评的选择小问算已评，教师可调整，学生自评中保持只读。

从工作区返回时仍可明确放弃未保存修改。离开页面不把未完成栏目当作已评，未评完的答卷不能发布/完成自评。发布后的教师批改或已完成自评继续只读，旧记录不自动重算。

## 原卷图片与栏目分值

图片上印有多个小问，但系统内只有一个整题作答区域时，无法仅凭图片可靠确定小问数量和官方分值。教师可在本题选择“按原卷拆分评分栏目”，填写小问名称与满分，合计必须等于本题总分，再逐栏评价。此设置只属于本次答卷，不改写原卷图片、题库或学生作答快照。

结构化多栏题可选择“调整评分栏目分值”，系统保留所有原有空格/小问，禁止删除或替换其中一栏来绕过必评要求。调整后需要重新逐栏确认。已保存的栏目定义随批改记录保存，学生能看到各栏结果。

旧计算题可能只给了整题总分，小问分值合计却不一致。本版按原小问权重换算到试卷快照总分；全部权重为0时暂按栏目数等分。界面会明确提示，这是网页评分分配，不能当作另行核实的官方小问分值。教师可以核对后调整；原始题目分值与内容保持不变。

## 保存与结果

整题一次提交全部人工栏目，服务器检查栏目ID、完整性、逐栏判定与分值、总分及批改修订号，通过后在同一事务中保存。缺栏、多栏、超分或旧修订号不会留下部分保存结果。学生自评只能提交人工栏目，不能夹带自动选择栏目或修改教师标准答案。

整题分数由各栏相加，状态和历史/首页统计继续按整题结果计算。教师公布前学生读不到本次反馈；公布后，学生在原始作答中查看逐栏分数、教师提供的正确答案与评语。旧版仅有整题评价的已发布记录按原样保留；尚未发布的旧多栏整题批改，重新保存时需要逐栏确认。

旧版尚未完成、且只有自动选择小问的自评记录，在学生主动点击“完成自评”时会按冻结题目与作答校准自动评分，避免旧分值明细阻塞完成。已经完成的记录直接返回原结果，部署不会批量重算历史成绩。
