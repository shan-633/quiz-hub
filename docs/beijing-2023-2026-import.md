## 作答与参考答案

每道题单独裁切原卷图文，多页题保留多个连续图块；原水印保留，没有AI重绘。OCR仅用于定位与核对，识别结果不替代可见题干。渲染整张原页后取像素区域，转为无损WebP，并逐图核验保存前后像素一致。

复用现有单选、多选、实验、科普阅读、计算模板。选择题原选项保留在图内，下方用A—D按钮作答；正确选项按原答案核对，多选使用全对2分、漏选1分、错选或未选0分。实验/阅读题使用一个整题开放作答区，按原题小问序号输入文字、手写或上传照片；不把原卷未明示的逐空分值伪装成官方配置。后续教师可以在编辑器中进一步拆分小问。

新增可复用的`solution.referenceImages`字段及折叠显示区，教师编辑、批改和学生已公布答案均能查看原卷评分说明。答案图片按本题题号裁开，并对并排图示单独划分；不将整卷答案页附给单题。学生未提交或教师未发布时，题目响应移除整个solution，图片直接地址也不可提前读取。打印仍为固定阅读版，整题原图采用较大的高度上限，避免把整段题干按小插图缩得不可读；不重复打印网页合成的选择按钮文字或作答提示。

## 检查入口

教师打开“题库与试卷”，在题库管理中搜索年份或地区。完整库可“管理题目”预览，或“推送班级”分配。两个问题库标题及说明会提示下载节选、待校对或源卷无答案。

导出的18份`.zqb.json`位于`output/import/beijing-2023-2026/packages/`，均使用现有导入协议校验；缺失内容的两个草稿库没有伪装成有效可发布导入包。该输出目录被Git忽略，避免把大量Base64图像重复写进源码；可使用下列命令从源PDF和已核对元数据重新生成：

```powershell
python scripts/render-beijing-collection.py
node --import tsx scripts/export-beijing-collection.ts
node --import tsx scripts/install-beijing-collection.ts
node --import tsx scripts/install-beijing-collection.ts --commit
```

默认安装命令仅校验，`--commit`才写入；可用`--data-dir`指定隔离目录，`--teacher`指定现有教师账号。稳定ID及导入指纹防止重跑覆盖已修改内容。源PDF副本在写入教学数据之前校验和保存；数据库提交失败会清理本次新增题图，重复安装会检查并恢复缺失的源副本。运行数据和导入备份不纳入Git。
