# 学生打印 PDF

学生登录后，在首页或题库页点击卡片上的「打印 PDF」。选择用途和字号，点「生成 PDF」；成功后显示实际页数、题目数和文件大小，可打开预览或下载。未登录时会先登录，再回到所选卡片。生成只读取题目，不创建、提交或改写练习。

阅读版用于看题、讲解；作答版额外提供姓名栏以及计算题、开放小问的书写区。两版均保留选择题选项、填空线、公式、表格和原图。试卷保持编排时固定的题目版本、顺序和分值；题库使用当前已发布题目，不含草稿。标准答案、学生已答内容、教师评语不会进入文件。

## 版式

采用A4竖排210×297mm，左右18mm、上16mm、下18mm。正文12pt或14pt、1.58倍行距，标题18pt，题号、类型和分值分层。中文字使用随PDF嵌入的思源宋体，数学公式使用KaTeX字体。页面以黑白为主，原题图片保留原色、水印及比例。

题目没有统一固定高度。短题尽量整题放置，长材料允许按段落、实验小问分页；图片与图注同页，表格跨页重复表头。小幅竖向选择题图可放到题干右侧；较大的多图仍横排或居中。图片高度最多55mm，宽度不超过正文区域。作答区按分值提供24–48mm，整道计算题48–80mm；需要更多草稿可另附纸。

设计参考本地北京中考资料版及期末卷的纸型、文字层级和图文排法，但默认12pt比所取样卷常见的约10pt更易读，因此不追求复刻原卷页数。具体尺寸是项目设计选择。[CSS分页规范](https://www.w3.org/TR/css-page-3/)、[CSS断页规范](https://www.w3.org/TR/css-break-3/)、[Puppeteer PDF参数](https://pptr.dev/api/puppeteer.pdfoptions)提供实现依据。

## 打印与设备

打印选择A4、竖向、实际大小/100%；双面打印选长边翻转。手机/iPad生成后使用PDF预览器保存、分享或打印。网页适配视口与真实iOS系统打印是不同的验收范围，后者仍需真机确认。

## 服务与部署

后端使用`puppeteer-core`启动独立的Chrome或Edge，不读取用户浏览器会话；默认查找常见Windows、Linux、macOS路径，也可在`.env`设置`PDF_BROWSER_PATH`为可执行文件绝对路径。服务器未安装浏览器时会返回明确错误；不需要额外Python或外部AI服务。中文字体及OFL许可证位于`content-assets/print/`，部署时需连同源码保留；KaTeX字体来自依赖。字体只在服务端使用，不给首页加载24MB字体。

生成页面内嵌受控本地图片和字体，不联网加载题干资源，不执行题干脚本。仅接受题干图片，拒绝答案附件、任意文件路径和远程图片；缺图时提示教师补齐。单次最多1000题、64MiB图片，同时最多两次渲染，每分钟每IP最多8次请求。过宽无法在最低可读字级排下的公式/表格会报错，需教师拆分后重新生成，不静默裁切。大量题目可能遇到生成超时，应拆分导出。

`POST /api/library/:id/pdf`请求JSON：`{"mode":"reading","fontSize":"standard"}`。`mode`可为`reading`或`writing`，`fontSize`可为`standard`或`large`；省略时采用阅读/标准。必须携带登录Cookie及`x-csrf-token`，响应为`application/pdf`，UTF-8文件名在`Content-Disposition`，页数和题数分别在`X-PDF-Page-Count`与`X-PDF-Question-Count`。响应禁止缓存，不支持请求包含答案。

## 重现样张

运行`node --import tsx scripts/export-print-samples.ts`，在临时数据库生成北京26题阅读/作答两份示例至`output/pdf/`，以及六题型大字版、长材料/百行表格验收样张至`tmp/pdfs/print/`，不改动运行数据。运行`python -X utf8 scripts/verify-print-pdfs.py`检查纸型、页码、题序、24幅原图、边界及跨页表头，并渲染每一页供人工检查（仅此验收脚本需PyMuPDF、Pillow）。样张不是新增题库，也不会加入首页。
