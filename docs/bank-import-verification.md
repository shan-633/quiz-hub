## 边界

本版是明确JSON协议的题库导入，不识别Excel/Word/PDF/ZIP，不做OCR、AI命题或AI判卷。导入新题库，不覆盖/合并旧题；开放题待人工评阅。幂等针对原文件文本（忽略开头BOM），修改格式空白也视为新文件。SQLite与图片文件的普通失败回滚已测试，不宣称跨进程/突然断电的分布式原子提交。
