# 学生学习概览

学生登录后，`/`为学习概览；完整展示练习目录仍在`/library`，班级任务、我的作答和站内消息入口保留。

## 正确情况热力图

最近12周每一天一格，按北京时间的交卷日期归档。点击日期可查看当天各份卷子的完全答对题数、部分得分题数、实际分数和作答入口，也支持方向键移动。旧记录缺交卷时间时以更新时间归档。

颜色按完全答对题数除以已评题数计算，多份试卷按题数合并，不取百分比的简单平均。100%深绿、90%以上绿色、85%以上浅绿、75%以上黄色、60%以上橙色、60%以下红色。部分得分不算整题全对，实际所得分数另行展示。题库练习与试卷作答均可统计，学生完成的自评注明“学生自评”。

只纳入全部完成评阅的作答。教师尚未公布或学生尚未完成自评时，用灰色斜纹和待评数量表示，既不显示中间成绩，也不作为0%参与统计。有已评与待评作答的同一天，格子按已评部分着色并附小圆点提示。没有交卷的日期显示浅灰，未来日期不能选择；没有成绩时显示破折号，不编造数据。

## 最新项目

- 最新收到：按推送时间显示最近4份班级任务，含教师、题数、分值、状态和开放/截止安排。点击定位班级任务中的对应卡片，开始作答仍走原有开放及限时校验。
- 最近作答：按更新时间显示最近4份记录，包括未答完、待批改、待自评和已批改；顶部可继续最近一份可用草稿，不依赖它是否仍在展示目录中。
- 教师消息：每位教师最近发来的一条消息，最多显示最近3位；消息节选最多240字，随后学生的回复不会替换它。预览不标为已读，点击进入对应会话后沿用原有已读规则。未读数量由实时聊天状态提供。
- 展示练习：最近加入的3项展示内容，可直接定位原有目录卡片。需要推送的内容只在收到任务后显示，不从教师全部题库中读取。

## 数据与刷新

复用`/api/attempts`、`/api/tasks`、`/api/library`及现有聊天SSE，不新增全量轮询或第二条聊天连接。页面进入时加载；手动刷新重新读取；页面重新可见、窗口获得焦点或恢复网络时刷新，自动触发间隔至少15秒。各区独立提示失败并可重试，不因一个接口失败隐藏其他模块。

作答摘要只增加交卷时间、快照总分和完整评阅的统计，不携带题干、答案、教师未公布成绩或作答原文；聊天摘要沿用当前用户的会话权限。新增消息查询索引，不改写题库、作答、班级或聊天正文。
