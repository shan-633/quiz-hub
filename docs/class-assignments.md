# 班级组、推送任务与时间设置（4.2）

## 教师使用

打开“管理学生”（`/teacher/students`），可以在“班级组”“全部学生”“推送任务”之间切换。管理员先建立师生关系，教师再将自己的学生分组；同一学生可加入多个组，也可保留未分组。教师不能借分组添加其他教师的学生。

点击“新建班级组”，填写名称并勾选学生；“管理成员”可改名、增减成员或删除组。删除组不会删除学生、作答或已推送任务。班级修改有版本保护，其他页面已修改时需刷新后重试。

导入题库并发布后，在“题库与试卷”卡片点击“推送班级”。勾选接收组，可选择截止时间、答题时限和“到时强制交卷”。重叠组内学生只收到一份任务；空组不能推送。推送的是当时已发布的题目、分值及规则快照，后续改题、改分组不会改变已发任务。任务仅出现在收件学生的“班级任务”中；原有供关联学生自主练习的目录继续保留。

题库/试卷的编辑弹窗也可设置默认“答题时限”和“到时强制交卷”，普通练习按该规则开始，推送弹窗可覆盖本次规则。原“预计时长”仍仅是学习建议；旧题库和旧答卷不会因升级突然开始倒计时。

“管理学生 → 推送任务 → 查看完成情况”显示收件学生的未开始、进行中、待批改、已批改及已截止状态，以及自动交卷或迟交标记。已交卷可进入原有批改页面，分数与答案仍由教师批改并发布。解除教学关系后，教师不再查看该学生答卷状态或批改；历史收件名单仍保留。

## 时间规则

题库和试卷的编辑弹窗新增“开放时间”，留空即立即可用。学生可提前看到标题和开放时间，但不能新建作答或打印试题；直接请求接口同样受服务器时间限制。已有答卷及历史记录保留，之后推迟开放时间不会锁住已开始的练习。教师预览和编辑不受此限制。

推送班级任务时可另设开放时间，任务实际使用题库当时开放时间和本次设置中的较晚者；不能通过推送提前绕过题库限制。推送后仍是独立快照，后来修改题库时间不会改写已发任务。若同时设置截止时间，开放必须早于截止。学生“班级任务”新增“未开放”分区，到时自动启用开始按钮，开始后才计算答题时长。

| 设置 | 开始与结束规则 |
| --- | --- |
| 开放时间 | 此时间之前不能新开始；留空表示无此限制 |
| 仅答题时限 | 从首次开始计时，例如开始后60分钟结束 |
| 仅截止时间 | 所有收件学生都使用同一绝对截止时间 |
| 两者都有 | 取统一截止与开始加时长中的较早者 |
| 未开启强制 | 超时提示，允许继续填写；超时提交标为迟交 |
| 开启强制 | 到时提交服务器已保存内容；截止后未开始的任务显示“已截止”，不能开始 |

答题时限允许1—600分钟。一次班级任务每位学生只有一份答卷，刷新、重复点击开始或打开多页均不会重置计时。若需要重做，教师应重新推送一份任务；普通自主练习仍可在交卷后“再练一次”，每次有独立记录。

截止时间在浏览器按本地时区选择，发送后保存为明确的UTC时间。以服务器时间为准，学生手动修改设备时间不会延长服务端期限。

## 学生使用

“班级任务”（`/tasks`）集中查看各教师的安排，按状态筛选。开始时会显示倒计时；最后一分钟改为提醒色。截止与时长同时存在时，显示本次实际交卷期限。刷新不会暂停或重置。完成后仍可从任务页及“我的作答”查看记录和批改状态。

强制到时时锁定输入、显示交卷提示，确认服务器已提交后自动退出到任务页；普通限时练习则返回“我的作答”。即使关闭页面或断网，服务器仍会交卷；网络恢复后页面会重新核对状态。断网时不会假装提交成功，仍保持锁定并重试。请在截止前确认文字、笔迹及照片已保存到服务器；未上传完成的照片和仅在本机的草稿不会在截止后补入已交答卷。

## 存储与部署

`class_groups`、`class_members`维护教师分组；任务题目快照保存在`assignments`文档，`assignment_recipients`保存收件名单和唯一答卷关联。`attempt_deadlines`按截止时间索引，单进程工作器每秒处理到期项并在启动时补交。答卷保存及照片上传在最终写入前再次检查期限，复用原有教师收卷、进度摘要及SSE。

接口包含`/api/teacher/students`、`/api/teacher/groups`、`/api/teacher/assignments`及`/api/tasks`；开始任务使用`POST /api/attempts`的`assignmentId`。教师组修改需要`expectedRevision`。任务快照、答案和计时字段由服务端建立，客户端不能指定任意开始时间或截止时间。

仍为单后端进程。备份SQLite与上传目录，才能同时保留分组、任务、答卷和附件。4.1部署前备份位置记录在本机忽略文件`data/class-assignments-backup.json`。当前局域网入口沿用`http://192.168.31.140:3001`。

4.2升级前备份记录在`data/opening-time-backup.json`，没有向旧题库或旧任务自动添加开放时间。
