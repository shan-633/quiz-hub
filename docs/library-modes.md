# 展示练习、分配任务与学生自评（4.3）

## 两种内容

题库和试卷都能选择“内容类别”。教师在“题库与试卷”编辑卡片设置，也可按全部、展示练习、分配任务筛选；题库/试卷页签与内容类别彼此独立。

| 类别     | 谁能看到                               | 交卷后                               | 非选择部分                     |
| -------- | -------------------------------------- | ------------------------------------ | ------------------------------ |
| 展示练习 | 管理员已关联给该教师的所有学生         | 立即公布标准答案、解析及选择题分数   | 学生对照答案自评               |
| 分配任务 | 教师点击“推送班级”后，只有收件学生可见 | 进入教师收卷箱，发布前隐藏分数和答案 | 教师批改、填写答案及评语后发布 |

展示练习需要先补全所有已发布题目的标准答案，才能发布或开始。仅单选、多选及混合题中的选择小问自动评分；填空、实验填空、阅读开放小问及计算题由学生自己判分，不自动匹配填空答案。混合题的自动部分保持只读，自评只填写人工部分的分数。

既有题库/试卷和新导入文件默认属于“分配任务”。升级不自动推送，也不把旧答卷改成自评；学生首页因此可能暂时没有展示卡片。教师可以把希望学生自主练习的内容编辑成“展示练习”，或将分配任务推送给班级组。导入协议仍为 v1.0，无须改造旧文件。

## 教师操作

自主练习：编辑题库/试卷 → 内容类别选“展示练习” → 补全标准答案并发布。关联学生在首页或“试卷与题库”可直接看到，未到开放时间时只显示标题及开放提示。展示练习不需要推送。

教学任务：内容类别选“分配任务” → 发布 → 推送班级 → 选择接收组、开放/截止时间、答题时限与是否强制交卷。沿用[班级任务规则](class-assignments.md)，每次推送冻结题目版本和规则；源库之后的改题不会进入已发任务。未推送给某学生时，该学生不能靠直接链接新建作答、打印或读取题干图片。

类别变更只影响之后的新练习入口，已有答卷保留创建时的批改方式、题目版本与计时规则。已有分配任务仍从“班级任务”进入；展示练习切回分配后，之前的展示作答仍可从历史继续或自评，但不能从该记录新开一份自由练习。需要学生重做分配任务时，教师重新推送。

学生自评不进入教师收卷与人工批改箱，自评分数单独标明，不能冒充教师成绩。聊天仍可使用，但“引用已交卷题目”仅列双方有权访问的教师批改答卷，不列学生自评记录。

## 学生操作

展示练习交卷后，原始作答锁定，答案立即可见。点击“开始自评”，左侧选题，中间对照自己的文字、笔迹或照片，右侧查看标准答案、解析，使用与教师端共用的正确/错误/部分正确控件。

正确对应人工部分满分，错误对应零分，部分正确填写两者之间的分值；自动选择分不能更改，零分主观小问也可确认。可记录自评备注，标准答案本身不可重写。每题保存后再切题，多页面冲突会提示载入最新记录；完成全部人工题后点击“完成自评”，确认后锁定。纯选择练习自动完成，无须逐题确认。

“我的作答”分为全部、未答完、待批改、待自评、已批改；待自评可直接继续。完成的自评记录标为“学生自评成绩”。分配任务仍等待教师发布后查看成绩、正确答案与评语。

展示卡片可“打印 PDF”；班级任务卡片可“打印题目”，使用选中那一次推送的题目快照，后续同库另一次尚未开放的推送不影响旧任务打印。均为固定 A4 阅读版，不含标准答案、个人作答与评语。开放前不能打印。

## 数据与接口

`LibraryItem.deliveryMode` 为 `showcase | assigned`，缺省按 `assigned` 处理；`Attempt.gradingMode` 为 `self | teacher`，随答卷创建时冻结，旧答卷缺省继续教师流程。没有批量改写旧题库或历史成绩。

自评使用独立 `selfReview` 状态、修订号及反馈，不写 `teacherFeedback`。`PUT /api/attempts/:id/self-review/:questionId` 接收 `expectedRevision`、`verdict`、`score`、`comment`；`POST /api/attempts/:id/self-review/complete` 接收 `expectedRevision`。服务端校验学生本人、已交卷、展示作答、人工部分分值及版本；不能修改自动分、其他学生或分配任务，完成后拒绝继续编辑。

教师发布权限、师生关系、开放与截止、图片授权及原有保存机制继续生效。升级前一致性备份索引在本机忽略文件 `data/library-modes-backup.json`，包含 SQLite 和附件。
