# 账号、教学归属与站内消息（4.0）

## 管理员从哪里开始

当前局域网入口为 `http://192.168.31.140:3001`。打开 `/login?admin=1`，使用本机 `data/admin-initial-credentials.txt` 中的账号和临时密码；首次登录必须设置12—128位新密码。现有 `teacher`、`student`、`student2` 的密码不变。遗留 `admin` 账号仍为停用，不要用旧密码尝试管理新系统。

全新安装时，在项目目录执行：

```powershell
node --import tsx scripts/bootstrap-admin.ts administrator --output data/admin-initial-credentials.txt
```

只能在没有启用管理员时初始化；已有账号或凭据文件不会覆盖。不带 `--output` 时仅向本机终端输出凭据。凭据文件和运行数据均被Git忽略，记录好新密码后可自行删除临时凭据文件。

## 账号与师生关系

管理员登录后进入 `/admin`。账号管理可按姓名/账号、角色和启用状态筛选及分页；创建账号、编辑姓名/角色、启用/停用、重置密码。创建和重置生成的临时密码只在本次弹窗展示，随后不能查回。新账号需首次改密；重置、停用和角色变更撤销现有登录。不能停用或降级最后一位启用管理员。

师生关系页先选择教师，再添加学生。一位教师可关联多个学生，一位学生也可关联多位教师。学生看到关联教师已发布的“展示练习”，分配任务须教师推送给所在班级后才可见。没有分配教师时会显示等待分配说明。管理员修改关系后，在线学生目录和联系人自动更新；恢复网络后重新校准。[内容类别与自评规则](library-modes.md)。

教师只能查看、选用、编辑和发布自己题库里的题目；试卷不能引用其他教师的题目，导入去重也按教师区分。教师的收卷、人工批改、作答附件和未交卷进度，仅包含本人试卷上当前关联学生的记录。共享同一学生不代表共享题库或该学生的其他答卷。管理员不会因为管理身份自动获得教师编辑权或聊天阅读权。

解除关系不删除作答。学生不能新开或继续相关练习，未答完记录标明教学关系已解除；已提交历史答卷及发布成绩保留本人只读。原教师不再查看或批改该学生记录，新教师也不会自动得到其他教师的旧答卷；恢复原关系可继续原教学流程。角色改变或停用后数据仍保留，按当前角色权限判断，恢复角色及启用后可继续使用有效关系。当前不提供跨教师迁移题库/旧答卷。

## 使用站内消息

学生与教师从“站内消息”或顶部消息入口进入 `/chat`。联系人仅来自管理员建立的有效师生关系。选择联系人即可开始私聊；桌面/平板采用左右两栏，手机以会话列表和详情分屏显示，可返回列表。

支持纯文字、换行、每条最多4000字符；发送按钮或Ctrl/⌘+Enter发送，输入法正在组词时不会误发。消息保存后实时通知对方，退出后再次登录仍可查看。未读位置在会话可见且消息区域到达底部时更新，后台页面不自动标读；一个设备已读会同步到其他设备。发送失败显示重试，同一发送标识不会产生重复消息。

“引用已交卷题目”只列出双方有权访问的教师批改答卷。消息只附题目链接和题号，不附学生原始答案、正确答案、解析或评语；学生反馈仍遵循教师发布流程。教师点击进入批改对应题，学生点击进入自己的作答。不能引用未交卷答卷、学生自评记录或其他教师的题。

解除关系后的原私聊历史保留双方只读，不能继续发送；恢复关系后沿用同一会话。停用或更换为不匹配角色后，原登录和对应聊天身份不可继续使用。

## 存储、通信及部署

账号和教学内容沿用SQLite；独立`teaching_links`与`admin_audit`维护关系和不含密码的管理记录。聊天使用`chat_conversations`、`chat_messages`、`chat_reads`，不写入答卷JSON；消息按会话和递增id索引，客户端以`clientMessageId`幂等发送。

核心接口：`/api/admin/users`、`/api/admin/relations`、`/api/admin/teachers/:teacher/students/:student`、`/api/auth/password`；`/api/chat/contacts`、`/api/chat/conversations`、`/api/chat/conversations/:id/messages`、`/api/chat/conversations/:id/read`、`/api/chat/events`。消息历史支持`before`倒序取较早页，重连支持`after`升序补齐，二者不能同时传入，每页最多50条。

聊天独立SSE只通知会话参与者，每15秒心跳，推送前复查会话，断开后获取摘要并按消息游标补齐。教师进度另有自己的订阅与按教师过滤的摘要查询。服务仍为单后端进程，多进程部署需要共享事件通道。

沿用`.env`的`HOST`、`PORT`、`APP_ORIGIN`等配置，局域网当前为`HOST=0.0.0.0`、`APP_ORIGIN=http://192.168.31.140:3001`。备份整个`data`目录同时覆盖账号、师生关系、消息、作答和上传图片；不要只备份题库。反向代理需关闭SSE缓冲并允许长连接。

首版包括师生私聊，不包含群聊、聊天附件、语音或系统通知推送。没有重新对4.0执行全站容量压测，旧性能实验不能作为本版性能倍率承诺。
