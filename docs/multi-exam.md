# 多学段、多学科与多地区考试

5.0 起，账号的角色与学习/教学方向分开设置。学生、教师都能保存最多30个方向，同一个人可以同时保留北京初中物理、浙江高中数学与全国大学英语等方向。

每个方向由学段、学科、考试地区、考试名称、可选的卷型/选科方案组成。学段提供小学、初中、高中、大学、职业与资格、其他；其余字段可选择建议项，也可自己填写。地区统一使用建议名称（如“北京”），卷型可加年份。系统不推定各省每年的中高考命题/选科政策。

进入“管理学习方向”或“管理教学方向”，添加后点击保存。顶部可切换一个方向或“全部方向”；没有填写具体方案的方向会包含同一学段/学科/地区/考试的各种方案。方向只负责内容和成绩筛选，不能授权新的试卷；师生关系、班级、推送、开放时间、限时与评卷规则独立执行。消息、学生和班级不会因切换学科而消失。

教师创建/编辑题库和试卷时填写考试分类。题目继承所属题库；题库和题目列表、推送任务、教师收卷与学生首页/历史/任务按当前方向筛选。新任务在推送时、新作答在开始时冻结分类，之后改库或归档不改变历史归属。删除个人方向也不删除内容或作答。

旧对象未填写分类时，只读兼容显示“初中 · 物理 · 北京 · 中考”，不批量重写旧题版本、学生作答、成绩。新的无分类导入文件会明确提示，并存成“其他 · 待分类 · 全国 · 未分类”，教师可编辑后再发布/推送。

导入协议仍为1.0，`bank`增加可选字段：

```json
{"curriculum":{"stage":"senior","subject":"数学","region":"浙江","exam":"高考","scheme":"2026 · 物理组合"}}
```

`stage`限primary/junior/senior/university/professional/other；学科/地区/考试1—80字，方案0—120字；拒绝未定义字段。现有六种答题机制及图文、公式、表格、小问内容块继续复用。本版没有凭空新增其他考试的真题，也没有新增英语听力、口语录音或自动过程判分。
