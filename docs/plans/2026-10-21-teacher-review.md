# 教师收卷与批改

学生交卷锁定作答，进入教师收卷箱。教师查看卷面快照、答题卡、文字、笔迹和照片，逐题判正确、错误或部分正确，保存分数、正确答案与评语，全部完成后发布。发布前学生只能看到收卷确认，发布后看到分数和反馈。

教师和管理员均可管理题库、批改本地系统内的已交卷记录。新增 teacher 演示账号。历史已交卷记录保持原样，教师可主动发起复核。使用可选 review 字段兼容旧数据，不覆盖题库或历史题目版本。

交卷时检查本次题目快照的全部标准答案。全部完整才对单选、多选以及混合题的选择小问初评；其他作答点无论是否作答都等待人工。自动初评可以覆盖，结果仍需教师发布。多选保留原题的半分规则。

批改与发布使用服务端事务及 expectedRevision，防止多个页面互相覆盖。未完成不能发布，已发布不可直接修改，重复交卷与发布不重置结果。答卷附件只允许本人及收卷后的教师访问；未交卷及未引用附件不开放。

实施顺序：
1. 为初评、答案完整性和全流程权限写失败测试。
2. 添加共享模型、选择题初评、教师接口、教师角色与附件权限。
3. 添加收卷箱、逐题批改工作台、学生等待及反馈界面。
4. 补充界面测试，运行完整测试、构建与独立审查。
5. 备份本地数据，部署并在桌面和手机宽度检查完整流程。

验收：六种题型均可手动批改；学生发布前无答案/成绩泄露；只自动判选择题；缺失答案时全卷不自动初评；冲突不会覆盖；旧记录保留；题库和试卷均能收卷；照片/手写可查看；刷新后可见发布结果。
