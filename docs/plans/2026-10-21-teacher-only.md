# 教学管理统一到教师端

按用户补充，本次不创建管理员系统或账号。保留学生与教师两端：题库、试卷、录题、文件导入、收卷和批改全部归教师。

前端路径为 /teacher（收卷）、/teacher/library（题库试卷）、/teacher/questions/:id（录题）；教学 API 统一为 /api/teacher。移除管理员导航、登录快捷入口及管理员教学权限。旧 admin 身份不再接受登录和既有会话，但保留其历史记录及资源所有权，避免破坏题库、快照和审计归属。新初始化只建立学生与教师演示账号。

将旧 AdminPage 及教学样式命名为 TeacherLibraryPage 和 teacher-library；页面与后端使用准确的教师权限。旧接口不提供功能；学生无权读取教师答案或管理内容。

步骤：先写路径、身份与旧会话失效的失败回归；迁移后端与前端；调整既有功能测试和协议下载地址；更新当前文档及生成的协议副本；完整测试、构建、独立审查；备份运行数据，部署并验证教师登录、题库、录题、导入及批改入口。教师原账号与全部教学内容保持可用。
