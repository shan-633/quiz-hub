# 每日一题与联系人状态（5.1）

学生登录后，首页展示每日一题和按月份排列的打卡日历。日期统一使用北京时间；每天首次点击“开始今日一题”时，由服务端随机抽取一道题，为该学生保存唯一的当天作答。无需每天运行抽题定时任务，未登录或未开始的日期保持空色。

题池限定为学生所属教师已发布、已开放的**展示题库**中的单选与多选题，且该题的标准答案必须完整。不从未推送的分配题库、未来开放的题库、其他教师题库、草稿或归档题目抽题。若题池为空，页面给出等待教师发布的提示。每日题覆盖学生有权访问的所有学习方向，切换首页方向不会换题。

题目和答案保存版本快照，老师修改源题不会改变当天作答。选答案、自动保存、提交、显示解析复用原有作答页；仅包含一道题，使用学生自评流程中的自动选择题评分。未选择答案不能提交。首次提交后答案锁定，刷新、重复点击和重复提交不会换题或修改结果；学生不能手动改选择题评分。多选按原题评分规则计算分数，但只有全对才在日历中显示绿色，部分得分和答错均为红色。未开始、未交卷是空色。

点击历史日期可查看对应答卷。未交卷记录可之后继续完成，结果仍归入抽题时的日期。教学关系解除后不能继续未交卷作答，已提交记录仍可查看。日历显示本月完成数和全对数，不引入额外积分或排行榜。

## 状态显示

当前系统的站内联系人是管理员建立关联的教师和学生；状态展示覆盖所有这些联系人，包括还没有创建私聊的联系人。联系人列表、最近会话、聊天详情标题均展示状态。解除关系后不再推送状态，历史只读会话不显示对方状态。

- 在线：页面仍在发送有效会话心跳。
- 做题中：当前打开自己的有效题库作答页，或每日一题作答页。
- 考试中：当前打开自己的有效试卷作答页。
- 离线：已退出登录、会话失效或心跳超时。

查看已交卷答案、历史记录、自评页不算正在做题。切出作答页或交卷后恢复在线。多页面取优先级最高的状态：考试中 > 做题中 > 在线；关闭其中一个页面不影响其他页面。正常关闭页面尽量发送离线提示；突然断网或关闭后，心跳90秒过期，每15秒清理一次，最迟约105秒显示离线。后台标签页可能被设备暂停，恢复后会重连并更新状态。

只广播状态名称，不发送试卷名称、题目、分数或答卷编号。心跳提供答卷编号仅供后端验证，服务端确认归属、教学关系、未提交状态和强制截止时间后自行判断类别。每个页面带递增序号，迟到的心跳不会覆盖新状态；支持最多20个未过期页面。心跳存于进程内，重启后重新建立状态，不写SQLite；聚合状态缓存后复用聊天SSE发送，不触发消息记录全量刷新。

## 接口与存储

- `GET /api/daily-question?month=YYYY-MM`：自己的月历记录及今日入口，无抽题副作用。
- `POST /api/daily-question/start`：事务内创建或返回当天固定作答。
- `GET /api/chat/presence`：关联联系人的状态快照。
- `POST /api/chat/presence`：`clientId`、递增`sequence`、可选`attemptId`/`offline`，沿用会话与CSRF校验。
- `/api/chat/events`新增`presence`事件；与消息事件独立，不增加额外SSE连接。
- `daily_questions(user_id,day,attempt_id)`以用户和日期为联合主键；完整作答仍放在原有`attempts`，增加`dailyDate`字段。日历颜色从已公布自动成绩读取，不复制可漂移的成绩字段。

升级只新增表和可选字段，旧作答、发布题目版本、师生与班级关系不需要迁移。
