# 作答结果：正确率反馈

日期：2026-10-21。依据用户要求修改已有结果页，不改变原答案、分值、判分记录或历史作答。

正确率 = 全对题数 / 已判题数。统计当前试卷内的题目，不以得分/满分加权；部分正确、错误、未作答均不算全对。待评阅或缺失判分记录的题目暂不进入分母；显示「已判题正确率」及待评阅数量。全部待评阅时显示中性「等待评阅」，不显示虚假0%或100%。有待评阅而已判题100%时，标题限定为「已判题全部答对」。

| 正确率范围     | 背景             | 标题                           |
| -------------- | ---------------- | ------------------------------ |
| 100%           | 深绿系 `#dcf4e6` | 全部答对，这次掌握得很扎实。   |
| 90% ≤ x < 100% | 薄荷绿 `#e7f5e8` | 表现很稳，再打磨一点细节。     |
| 85% ≤ x < 90%  | 浅绿 `#eef7e7`   | 基础扎实，继续保持这个节奏。   |
| 75% ≤ x < 85%  | 黄 `#fff5d7`     | 还有薄弱点，值得回头再练。     |
| 60% ≤ x < 75%  | 橙 `#ffead6`     | 需要留意，先把关键知识补牢。   |
| x < 60%        | 红 `#fde5e4`     | 先停一停，把基础一步步补回来。 |

按实际正确率确定档位；展示最多一位小数，向下截断，避免99.95%显示成100%。得分仍保留在各题判分信息中。

答题卡：correct绿色，incorrect/partial/unanswered红色，pending灰色；未提交的answered用蓝色，empty中性。选中状态只在透明伪元素上绘制蓝紫呼吸外圈，不替换背景或文字颜色。减少动态效果设置下保持静态外圈。手机横向答题卡预留7px，容纳外圈和光晕。

验证：`npm test -- --maxWorkers=4` 共20个文件88项通过，新增17项测试涵盖分档边界、题数统计、部分正确/未作答、待评阅、显示精度及切题状态；`npm run build` 通过。独立只读复核无Important/Critical问题；手机外圈留白建议已处理。

浏览器用既有作答只读验收：混合结果1/5=20%为红色，100%为绿色；正确/错误/待评阅按钮计算样式分别为rgb(227,243,232)、rgb(251,231,229)、rgb(238,241,245)。选中错题后背景保持红色，伪元素动画名question-current-pulse，填充为透明；未生成或修改学生答案。
